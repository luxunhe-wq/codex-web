**使用网页版前，必须先安装并配置好 Codex CLI，确认终端能够正常对话。**
原生部署使用同一 Linux 服务器、同一运行用户的 Codex；[Docker 部署](DOCKER.zh-CN.md)自带 CLI，需要在容器内配置。
完成自己的 Codex 登录或模型服务配置后，再按[中文首页](../README.md)的步骤安装并启动网页。
